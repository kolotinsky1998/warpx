Схема реализованной логики: 2D XZ, By перпендикулярен плоскости, electrons = gyrokinetic, ions = boris (per-species override).

Логика изменений (по шагам выполнения)

  1. Парсинг: глобальный algo.particle_pusher + локальный <species>.particle_pusher.
  2. Для gyro-species создаются runtime-атрибуты скорости гироцентра u_gc.
  3. В push-кернеле считаются: v_E, разложение на v_parallel/v_perp, поворот v_perp, затем v_gc и полная v.
  4. Положение particles для gyro-species обновляется по u_gc; импульс ux/uy/uz остаётся полной скоростью.
  5. Strict-check: если поле не удовлетворяет Bx≈0, Bz≈0, |By|>0, симуляция аварийно завершается.
  6. openPMD metadata отражает реальный выбранный pusher на уровне species.
